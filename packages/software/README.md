# pydantic-ai-factory-software

Software stations for [Pydantic AI Factory](https://github.com/hnrly/pydantic_ai_factory).

This package will hold the stations of a software factory, starting with Design. It depends on the generic core, `pydantic-ai-factory`. The core never depends on it, and a check in CI enforces that.

No station ships yet. The Design station arrives once the core contract is in place.

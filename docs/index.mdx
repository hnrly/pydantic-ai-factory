Pydantic AI Factory is a Python library for building AI factories. A factory is a repeatable production system. It takes a mission, moves the work through stations, and proves each result with evidence before a person approves it. Your agents stay ordinary Pydantic AI agents; the factory adds the record of what they produced, how it was judged and who approved it.

Install it with `pip install pydantic-ai-factory`. The public API may change before 1.0. These pages grow with the code: each pull request adds the page for what it builds, and every Python sample is run by the test suite.

## Where it is going

The first factory is the [software factory](software-factory.md). Its first station, [Design](design-station.md), turns a short mission into a reviewed design that a person approves. [Getting started](getting-started.md) builds a small factory of your own in a few lines. Build, Quality and Release follow, one station at a time; the [roadmap](roadmap.md) says what comes next.

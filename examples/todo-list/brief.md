A to-do list web page where I can add tasks and tick them off.

Type a task and press Enter to add it to the list. Tick a task's box to mark it done,
and untick it to bring it back. Pressing Enter on a blank task adds nothing. The list,
and which tasks are ticked, stays the same after the page is reloaded.

Keep it to one page that opens in a browser with nothing to install. No accounts, no
sharing between devices and no due dates.
